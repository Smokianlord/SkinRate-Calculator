# 🎮 SkinRate Calculator Pro v3.0.0 Release Notes

Welcome to the **v3.0.0 Release** of **SkinRate Calculator Pro**! This release brings a streamlined desktop UI, unified transfer rates, normal 85/$ presets, a brand new multi-resolution icon, and root directory executable placement.

---

## 🌟 What's New in v3.0.0

### 🚀 1. Streamlined Transfer & Cashout Calculations
- **Merged Skin & Steam Wallet Rate**: Skins and Steam wallet transfers share the same calculation. Unified into a clean, single rate input and card.
- **Normal Rate Preset (85/$)**: Default rate is now set to **85/$** (with preset chips `80`, `82`, `85`, `87`, `90`).
- **Removed Irrelevant Metrics**: Cleaned out cluttered/redundant rows (`Cash in Hand (-1.85%)`, `Savings vs Item`, `Effective BDT Cashout`, and `Extra USD vs Item`).
- **Simplified 15% Steam Tax**: Direct, clean breakdown:
  - `With 15% Tax`
  - `Without 15% Tax`
  - `Base Amount`

---

### 🎨 2. New App Icon & UI Polishing
- **Brand New v3.0 Multi-Resolution Icon**: Designed a modern CS2-themed dark metallic and cyber-blue app emblem (`skinrate.ico` with 256x256, 128x128, 64x64, 48x48, 32x32, 16x16 layers).
- **Dedicated Sub-Navigation Bar**: Removed the repetitive *Steam Market & Profit* tab and placed the remaining 3 modes into a spacious, centered tab bar with **zero cut-offs**:
  - `⚡ Rate Calculator`
  - `⇄ Reverse Calculator (৳ ➔ $)`
  - `📊 Rate Cheat Sheet`
- **Sleek Minimalist Copy Buttons**: Replaced large repetitive buttons with subtle, compact copy buttons that smoothly morph to a green `✓` when clicked.

---

### 📁 3. Direct Root Folder Executable & Clean Repository
- **Convenient Root Placement**: `SkinRate Calculator.exe` is now generated directly inside the main repository folder for instant 1-click launching.
- **Removed Obsolete Versions**: Cleaned out the legacy `Old Version/` folder.
- **Dual Release Distribution**:
  - `SkinRate-Calculator-v3.0.0-Windows.exe` (Single-file portable executable)
  - `SkinRate-Calculator-v3.0.0-Portable.zip` (Fast-launch folder version)
  - `checksums.txt` (SHA-256 hashes)
